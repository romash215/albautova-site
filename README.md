# Сайт Виктории Албаутовой

Одностраничный сайт карьерного и life-коуча, эксперта по брендингу и коммуникациям.
Статический — без сборки и зависимостей.

## Структура

```
index.html        разметка обеих страниц
css/styles.css    все стили
js/main.js        анимации и переключение страниц
```

Внутри `index.html` две «страницы» в одном файле:

- `#page-home` — главная (обо мне, опыт, направления, встреча-знакомство)
- `#page-brand` — мастерская личного брендинга (8 сессий, форматы)

Переключение — по клику на элементы с атрибутом `data-go="brand"` / `data-go="home"`.
Отдельной перезагрузки нет, всё работает на одном файле.

## Как вносить правки

**Тексты** — в `index.html`. Берутся дословно из Google-документа «Для сайтов»,
вкладки «🥰 Основной сайт» и «💌 Сайт Личный брендинг». Не переписывать своими словами.

**Цвета** — в начале `css/styles.css`, блок `:root`:

| Переменная | Значение |
|---|---|
| `--cream` | фон |
| `--spirit` | индиго, духовные сессии |
| `--worth` | ягодный, самоценность |
| `--career` | бирюза, карьерный коучинг |
| `--brand` | изумруд, брендинг |
| `--btn` | кнопки |

**Стили страницы брендинга** — все с префиксом `#page-brand`, чтобы не задевать главную.

## Локальный просмотр

```bash
cd albautova-site
python3 -m http.server 8000
```

Открыть http://localhost:8000
